One place. Everything you run.

The overview stays short on purpose. When something breaks you see it first, and the details are one tap away.

Your network

You, router, ISP, internet. See exactly where it broke, not just that it did.

Hosts

CPU, memory, disks, updates and reboots, with history and no metrics stack to run.

Docker & services

Stopped containers, restart loops and failed systemd units, caught as they happen.

Kubernetes

Nodes, pods, Helm and Argo CD. Know when a node drops or an app drifts from Git.

Calm alerts

Presets, quiet hours and a daily summary. Discord only pings you when it matters.

Running in three steps.

One server, one small agent per machine. It runs fine on a Raspberry Pi, and you never open a port on your hosts.

It sees everything. So it's built to be boring to attack.

  
CronRack is open source and every line is public, so you can check all of this yourself.

  

    
Outbound only
Agents connect out over TLS. Nothing listens on your hosts.

    
Read-only by default
No shell, no remote commands. Kubernetes access uses a read-only role.

    
Scanned on every build
Images with fixable high or critical vulnerabilities are blocked before release.

    
Stays home
Self-hosted, no telemetry, no cloud account.
